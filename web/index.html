    This makes a script you run once. It:

    • Keeps no logs: no journal, no syslog, /var/log in RAM, no swap, no core dumps.
    • Wipes a device's IP from memory a few minutes after it goes quiet.
    • Runs its own DNS with no query logs, blocking ads and trackers by default.
    • Removes provider agents, usage stats, snap, crash reporting and Ubuntu's ad pings.

    • Deletes its setup traces. Your provider still keeps its own copy of this script.
    • Exits through Cloudflare WARP, unless you turned it off.
    • Installs security updates automatically, and restarts WARP or DNS if they stop working.

    Why you don't have to trust us
    
      
    
        
    
          
    No server
    
          
    rollavpn is static files. Its Content-Security-Policy only lets it reach the four provider APIs, so it can't send anything to us.
    
        
    
        
    
          
    Your keys
    
          
    Keys are made in your browser and only leave in files you download. The server's key travels in its setup script, which your provider (and SporeStack, if used) can see.
    
        
    
        
    
          
    Nothing to log in to
    
          
    SSH is off and root is locked unless you add a key. The only way in is WireGuard.
    
        
    
        
    
          
    Read it first
    
          
    Step 4 shows the exact script. The whole app is about 2,600 lines, with no build step.
    
        
    
      
    
    
    

    
    
      
    Open source
    
      
    
        
    
          
    WireGuard
    
          
    WireGuard is small enough to read, built into Linux since 5.6, and its protocol has formal proofs. The server uses the version in Ubuntu's kernel.
    
        
    
        
    
          
    Build it yourself
    
          
    Skip app-store binaries and build from the official source. On Linux:
    
          
    git clone https://git.zx2c4.com/wireguard-tools
make -C wireguard-tools/src
sudo make -C wireguard-tools/src install
    
          
    The other apps are in wireguard-apple, wireguard-android and wireguard-windows.
    
        
    
        
    
          
    Someone else's hardware
    
          
    A cloud server runs on someone else's computer. Its owner can read memory, copy the disk and watch traffic. No logs means nothing to hand over, but nothing on the server stops a host that's watching.
    
        
    
        
    
          
    True of every VPN
    
          
    Any VPN's "no logs" is a promise about hardware you can't inspect. rollavpn limits what one host can learn instead: pay anonymously, add a second hop, delete old servers. The only hardware you can fully trust is your own.
    
        
    
      
    
    
    

    
    
      
    What it does and doesn't do
    
      
    
        
    
          
    It hides you from
    
          
    The Wi-Fi you're on and your ISP. Sites see the server's IP, not yours.
    
        
    
        
    
          
    Anonymity
    
          
    Your provider knows who pays. Use SporeStack so nobody does, and Second hop so no host sees both ends. Without WARP, sites see an IP only you use; a fresh server now and then breaks the link.
    
        
    
        
    
          
    It can't hide you on a site
    
          
    Logins, cookies and fingerprinting still identify you. Use separate browsers for separate identities, or Tor Browser.
    
        
    
        
    
          
    VPN detection
    
          
    Some sites block cloud IPs. WARP helps, but its addresses are still listed as VPN. Only a home connection looks like home, which is what Your own server is for.
